# Cassandra MCP

Queries an Apache Cassandra cluster. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/cassandra-mcp

Installs from the Camillia hub as `cassandra-mcp-6db81d`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
